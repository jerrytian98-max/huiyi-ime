# 会意输入法 · Android 使用说明

**听懂话，看懂意。** 英文名称为 Huiyi Keyboard。0.1.7 起统一使用会意品牌，命名范围及覆盖安装说明见 [BRANDING.md](BRANDING.md)。

基于 [Trime / 同文输入法](https://github.com/osfans/trime) 与 Rime。当前公开版本 0.1.41-ai，包含中英文键盘、语音转写、AI 文字整理和用户主动截屏后的聊天回复建议。

**下载：**[最新版 Android arm64 APK](https://github.com/jerrytian98-max/huiyi-ime/releases/latest/download/huiyi-android-v0.1.41-arm64-debug.apk) · [所有版本](https://github.com/jerrytian98-max/huiyi-ime/releases)

## AI回复方式

「会意输入法 → AI 设置 → 提供多个回复选项」默认关闭：短按或长按 AI回复后，直接把第一条回复写入截图前的输入框与光标位置。开启并保存后，显示三条回复供选择。无法确认原输入位置时不会写入其他输入框；应用可能提示确认或复制回复。程序不会点击聊天应用的发送按钮。

## 整理当前输入框

0.1.31 起，点“整理”时若没有选中文字，会尝试读取当前输入框的完整草稿，生成预览；确认后核对原文并整段替换。已有选区时仍只整理和替换选中部分。读取不完整或超过6000字符时会明确提示，不会截取光标附近的一小段冒充全文。编辑后插入同样会在返回原输入框时重新核对整段草稿；原文变化则复制结果，避免误覆盖。

## AI回复风格

0.1.30 起，AI回复默认使用简短、直接、自然的聊天语气，减少生硬客套和过度礼貌。在「会意输入法 → AI 设置 → AI回复系统提示词」可自行修改风格，点击「保存设置」后生效；留空使用默认风格。「恢复默认回复风格」可重新填入默认提示词。此设置只影响截图生成的回复建议，不改变语音转写或文字整理。截图识别、输出格式及不编造事实等规则仍会生效。

0.1.22 将“AI回复”窗口下移，上边缘与键盘工具栏顶部对齐。长回复的窗口高度限制在键盘区域内，列表可滚动查看。

## 长按空格语音直输

0.1.21 支持在全键盘和九宫格上长按空格说话，松开停止录音。空格键显示录音秒数和转写状态，云端返回后将识别原文直接输入原输入框的光标位置。有选区时替换选区，保留两侧文字。开启嵌入式候选预览时，输入框中已显示的未确认文字会保留。首次使用需要麦克风权限，授权后回到输入框重新长按。

普通短按空格仍用于输入空格或确认候选。录音期间上滑离开按键可取消。移动光标、继续按键、切换输入框或关闭键盘会放弃本次语音及待返回结果。过短、静音或失败的录音会提示重试。最长录音60秒，到上限停止麦克风并等待松开后上传。

此入口使用 AI 设置中已启用的云端语音服务，默认腾讯云通用中文。选择 English 后使用英文模型。文字整理仍可通过键盘工具栏“语音”或“整理”入口使用。语音识别需要网络，松开后的等待时间取决于网络和服务响应。

## 腾讯云语音识别

0.1.20 默认使用腾讯云通用识别。中文模型为 `16k_zh`，在 AI 设置选择 English 后自动使用 `16k_en`。完成录音后上传音频，转写再交给 DeepSeek 整理，核对后插入原光标。录音最长60秒，取消或离开输入界面会停止录音并取消处理。

新安装使用通用云端配置，旧内测预置的 `16k_zh_en` 首次升级自动切到通用中文。已有其他自选腾讯云模型、自定义兼容接口和用户后来选择的系统语音方式会保留。设置位置为「会意输入法 → AI 设置 → 腾讯云识别模型」。

腾讯云 AppID、SecretId 和 SecretKey 独立配置，SecretId、SecretKey 使用 Android Keystore 加密保存。公开版不附带开发者的服务凭证，请在 AI 设置填写自己的凭证。兼容接口支持独立语音 Key，留空时沿用文字 Key。

0.1.19 已在 API 35 模拟器通过中文、英文真实云端识别及 DeepSeek 整理，以及注入麦克风后的完整录音、预览和光标插入。0.1.20 重新验证默认值、升级迁移和中英文文件直传识别。前一版中英大模型的4004额度问题保留在历史测试记录中，当前默认使用已测通的通用模型。实体 One UI 手机和真人麦克风仍待验证。

官方接口说明见 [腾讯云录音文件识别极速版](https://cloud.tencent.com/document/product/1093/52097)。

## 九宫格与全键盘

在「虚拟键盘 → 中文键盘布局」切换全键盘（26键）和九宫格（9键），默认26键。两种布局均使用雾凇词库，英文、密码和邮箱使用全键盘。三个内置主题已移除隐藏、剪切、复制、时间、方案、编码等功能的长按绑定及提示，保留符号长按输入。详见 [KEYBOARD_LAYOUT.md](KEYBOARD_LAYOUT.md)。

0.1.12 进一步清理数字和符号页：移除全部次级长按／滑动功能与上方提示，删除页内的“迷你”“数字”快捷键，并重新分配按键宽度。

## AI 服务配置

公开版不会预置共享 API Key。请在「会意输入法 → AI 设置」填写服务商提供的 HTTPS Chat Completions 地址、文字模型、视觉模型和 API Key；语音识别可另行配置腾讯云或兼容的音频转写接口。保存后即可使用对应 AI 功能。服务费用由用户与服务商的协议决定。密钥使用 Android Keystore 加密保存在本机，但发送给模型的文字、录音或截图会交由所选服务处理。

## 默认存储空间

0.1.6 起固定使用应用专属存储空间，首次向导只保留“启用输入法”和“选择输入法”。设置中的存储模式及用户文件夹仅展示，不再提供存储模式或外部目录选择。

旧版外部同步模式在启动时自动切换。此前同步到应用专属目录的词库、用户词频和配置保持原样；原外部目录及其引用不删除，但不再自动与外部目录同步。该变更不主动导入尚未同步的外部文件。卸载应用会清理应用专属目录，请事先导出需要保留的数据。

## 雾凇拼音与简体主题

默认中文方案已改为“雾凇拼音”，随包提供完整词库、中英混输和 Lua 扩展，无需联网下载。默认输出简体；首次编译完整词库可能需要数分钟，部署完成后使用本地缓存。旧版首次升级会备份输入法配置并自动切换到雾凇；原有方案、词频文件和其他配置保留，之后手动选择的方案不会被反复重置。

默认主题更新为“轻简·简体”，保留浅灰白键与绿色主要操作。三个内置主题的按钮/提示均改为简体，“西文、剪下、贴上”统一为“英文、剪切、粘贴”。外部自定义主题保留原样。详细来源、迁移与验证见 [RIME_ICE_INTEGRATION.md](RIME_ICE_INTEGRATION.md)。

## 历史接入：Tokenlink / hy4

0.1.3的默认地址为 `https://tokenlink.woa.com/openapi/v1/chat/completions`，文字与AI回复模型均为 `hy4`。已加入实测有效的 `no_think` 请求参数，并通过 Android 生产客户端的中英文流式整理、截图三条建议测试。当时API Key不内置；0.1.5已按用户要求加密附带DeepSeek内测默认Key。已有配置会保留，升级后请核对地址和两个模型。

电脑可直连接口；当前模拟器无法直接解析该域名，Android 实测通过电脑临时测试转发完成。手机需具备能访问该服务的网络，直连与真机兼容性仍待验证。该历史版本尚未配置语音转写接口，以系统语音为默认方式。0.1.19 已改为腾讯云默认配置。本轮没有调用 hy3 或 OpenAI 模型。

详细结果和复现见 [TOKENLINK_HY4_VALIDATION.md](TOKENLINK_HY4_VALIDATION.md)。

## 安装与首次使用

1. 安装 `huiyi-android-arm64-debug.apk`（多数现代安卓手机）。要求 Android 8.0 及以上。x86_64 包用于模拟器。
2. 打开应用，在两步向导中启用并切换至会意输入法；存储空间自动使用应用专属目录，无需选择目录或授予外部文件夹访问权限。第一次部署词库需要等待；默认已选择雾凇拼音；如手动切换，可在方案菜单中重新选择“雾凇拼音”。
3. 打开任意聊天输入框。键盘上方有“语音”“整理”“AI回复”三个入口，长按任一入口打开 AI 设置；设置首页列表中也有“AI 设置”入口（位于“常规”上方）。
4. 普通拼音和英文输入无需 AI Key。语音云识别需在 AI 设置中自行填写腾讯云凭证，或配置兼容的音频转写服务。
5. 在 AI 设置填写**完整的 HTTPS Chat Completions 地址**、文字模型、支持图片的 AI 回复模型及自己的 API Key。文字整理和截图回复共用服务地址与 Key；语音凭证可单独设置。

选择兼容接口转写时，需要配置 multipart Audio Transcriptions 接口。聊天地址不能作为音频转写地址使用。此前0.1.1验证过的 OpenAI 示例地址为 `https://api.openai.com/v1/audio/transcriptions`，语音模型 `gpt-4o-mini-transcribe`，已经过真实音频请求验证。兼容接口可单独填写语音 API Key，留空时沿用文字 Key。腾讯云使用独立凭证。云端转写和 AI 整理分别产生请求费用。

## 三个 AI 入口

- **语音**：首次授予麦克风权限后，返回聊天框再次点语音。系统模式显示服务提供的临时转写；云端模式在内存中录音，点击“完成”后上传并转写，最长60秒，不提供录音期间的文字预览。取消或关闭键盘会停止录音并放弃本次请求；静音或过短录音会被拒绝。转写后显示 AI 整理稿和原文，核对并选择插入。未配置文字 AI 或整理失败时可使用转写原文；等待整理时也可立即选择原文。
- **整理**：直接点击会尝试整理当前输入框的完整草稿；已有选区时只整理选中文字。结果预览确认后替换原文或选区。支持中文与英文，最多一次 6000 字符。AI 被要求保留数字、姓名、原意和不确定性。
- **AI回复**：普通模式由系统请求截屏授权，采集一帧后结束。Android 11 及以上可在会意 AI 设置开启“快捷截屏（免重复确认）”，阅读说明后手动授予“会意快捷截屏”无障碍权限；保持授权期间点击即可直接截取一张屏幕并分析。未授权或关闭后恢复普通模式。默认直接填入第一条回复；开启“提供多个回复选项”后显示三条供选择。程序不会自动发送消息。受保护内容仍由系统遮蔽或拒绝采集。

截图结果返回时，若仍在原输入框且文字未变化，会显示建议。若键盘关闭、切换输入框或关闭通知权限，返回键盘再次点“AI回复”可查看进度、错误或建议；输入目标变化时会复制结果，供手动粘贴。再次截屏可在结果窗口选择“重新截屏”。密码及标记为不允许个性化学习的输入框禁用 AI 操作。

## 数据与权限

普通键入由本地 Rime 处理。用户选择云端语音后，工具栏语音的“完成”或60秒上限会上传录音；长按空格入口在松开后上传录音到配置的转写服务，并将识别原文直接插入原位置。点击整理会将所选文字，或无选区时当前输入框的完整草稿发送到文字服务；语音整理发送转写文字。AI回复会发送整张当前屏幕图片，可能包含聊天以外的信息。服务商处理和保存数据的方式由其政策决定。请只配置你信任的服务。

AI 模块不把录音、截图或转写写入文件；待插入结果仅在进程内暂存，进程结束会丢失。API Key 通过 Android Keystore 的 AES-GCM 加密保存；应用禁止备份与明文 HTTP。Rime 词库学习、原有剪贴板历史与调试日志功能沿用 Trime，具体可在设置管理。详细说明见 [PRIVACY.md](PRIVACY.md)。

## 构建

```powershell
powershell -ExecutionPolicy Bypass -File script/Build-Android.ps1
```

此工作区的工具位于上一级 `.tools`：JDK 17、Gradle 9.8.1、SDK platform 37 / build-tools 37.0.0、NDK 30.0.16248370、CMake 4.1.2。完整拉取子模块：

```powershell
git submodule update --init --recursive
```

Windows 下脚本创建英文目录 junction，避免 Android/NDK 中文路径问题。词库在构建目录中展开，不要求 Windows 创建文件符号链接的管理员权限。Boost 首次构建需要下载约 103 MB；构建会核对 SHA256。产物位于 `app/build/outputs/apk/debug`，独立包名 `com.rimeai.keyboard.debug`，可与上游同文并存。当前为调试签名测试版本；正式分发需要自己的持久签名及 release 构建。
